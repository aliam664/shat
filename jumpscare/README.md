# 🎀→💀 jumpscare — نسخهٔ حرفه‌ای (v2)

صفحه‌ای که مثل یک **اپ پیام‌رسان واقعی** شروع می‌شود، به یک **ویدیوی found-footage** تبدیل می‌شود و در آخر با یک **جامپ‌اسکر سینمایی** کارش را تمام می‌کند.

---

## 📁 ساختار

```
jumpscare/
├── src/template.html      ← تنها منبع حقیقت (همهٔ کد و متن اینجاست)
├── assets/                ← تصاویر اصلی (کیفیت بالا، برای نسخهٔ آنلاین)
│   └── light/             ← نسخهٔ سبک تصاویر (فقط برای تک‌فایل)
├── test/smoke.mjs         ← تست خودکار کل مسیر بدون مرورگر
├── build.py               ← سازندهٔ خروجی‌ها
└── ../docs/               ← خروجی‌ها (گیت‌هاب Pages از همین می‌سازد)
    ├── index.html             نسخهٔ آنلاین
    ├── assets/*.jpg
    └── jumpscare-single.html  تک‌فایل (تصاویر base64 داخل خودش)
```

**ساخت مجدد بعد از هر تغییر در قالب:**

```bash
python3 jumpscare/build.py
```

## 🎬 معماری روایت (چرا این‌طوری ترسناک‌تر است؟)

| # | صحنه | تکنیک ترس |
|---|---|---|
| ۱ | **دروازهٔ صدا** | بهانهٔ منطقی برای باز کردن صدا + هشدار واقعی (عذاب وجدان اخلاقی) |
| ۲ | **چت واقع‌گرایانه** | سه عکس بی‌ضرر؛ در عکس سوم **یک آدم در تاریکی راهرو ایستاده** — بذرِ ناخودآگاه ترس |
| ۳ | **شیت مجوز** | کاربر را برای صدا و لرزش آماده می‌کند؛ «دسترسی دوربین برای ضبط واکنش تو 😈» |
| ۴ | **ویدیوی found-footage** | داستان ۱۷ ثانیه‌ای: هم‌دریفت دوربین روی دست، تایم‌استمپ زنده، REC چشمک‌زن، خطوط VHS، سوسوی چراغ، زیرنویس تایپ‌شونده، **ضربان قلب که از ۶۲ به ۱۲۸ می‌رسد**، شکلِ توی درگاه که آرام بزرگ می‌شود |
| ۵ | **جامپ‌اسکر ۱۵ ثانیه‌ای** | ۷ ضربهٔ کارگردانی‌شده: جیغ، خنده، غرش، چرخش ۱۰۸۰°، **۹ ثانیه سکوت مرگ‌آور و سیاه**، و ضربهٔ نهایی که کاربر فکر می‌کند تمام شده |
| ۶ | **پایان** | آمار ترس (زمان فلج‌شدن، شدت صدا، شمارندهٔ قربانی) + لینک زنجیره‌ای برای قربانی بعدی |

**نکتهٔ کلیدی طراحی:** ۹ ثانیه سکوت عمداً بعد از اوج می‌آید. مغز انسان «پایان» را اعلام می‌کند، عضلات شل می‌شوند و همین‌جاست که ضربهٔ دوم بیشترین اثر را می‌گذارد.

## 🔊 موتور صدا (Web Audio API — بدون هیچ فایل صوتی)

```
منابع (اسیلاتور/نویز)
      ↓
  StereoPanner        ← چپ/راست برای حس فضایی با هدفون
      ↓
   GainNode
      ↓
DynamicsCompressor    ← threshold -6dB, ratio 18:1 (فشرده = بلندتر)
      ↓
 WaveShaper soft-clip ← اشباع هارمونیک، «بلندترین صدای ممکن»
      ↓
   GainNode ×2.2      ← سقفِ بلندی (قابل تنظیم با ?intensity=)
      ↓
   مقصد (بلندگو)

Convolver (reverb اتاق) ← از باس جدا تغذیه می‌شود
```

افکت‌های ساخته‌شده: ضربهٔ ساب، جیغ (ساو+اسکوئر با LFO)، غرش، زمزمهٔ استریو، غژغژ در، ضربهٔ خفه، خندهٔ شیطانی، زنگ پایان، انفجار پارازیت، و **ضربان قلب با BPM فزاینده**.

مرورگرها اجازهٔ تغییر **ولوم سیستمی** را نمی‌دهند؛ این زنجیره کاری می‌کند که صدا با حداکثر شدت ممکن پخش شود و «شبیه» ولوم‌کشی خودکار به نظر برسد.

## ⚙️ پارامترهای آدرس (برای کنترل دقیق)

| پارامتر | کار |
|---|---|
| `?intensity=1.5` | شدت کلی (۰٫۲ تا ۲) — روی صدا، لرزش و لرزهٔ دوربین |
| `?mute=1` | کاملاً بی‌صدا (برای تست) |
| `?fast=1` | سریع: کل ۳۵ ثانیه در ~۱۲ ثانیه |
| `?name=علی` | اسم قربانی در پیام پایانی |
| `?r=1` | حالت زنجیره‌ای (نسخه‌ای که برای «قربانی بعدی» می‌فرستی) |
| `?selftest=1` | اجرای خودکار تست داخلی و لاگ در کنسول |

## ♿ دسترس‌پذیری و ایمنی (کد، نه شعار)

- `prefers-reduced-motion` → **فلاش استروب کاملاً قطع** و شدت کم می‌شود.
- دستگاه لمسی → شدت فلاش کمتر، در عوض ویبره.
- صفحهٔ اول هشدار واقعی می‌دهد (قلب/حساسیت نوری) و قابل رد کردن است.
- `Esc` وسط جامپ‌اسکر غیرفعال می‌شود تا کاربر «گیج» شود، ولی صفحه بعد از ۱۵ ثانیه **قطعاً** آزاد می‌شود.
- هر خطای صوتی با محافظ `wrapAudio` بی‌اثر می‌شود: **صدا هیج‌وقت نمایش را متوقف نمی‌کند**.

## 🧪 تست

```bash
cd jumpscare/test
npm install
node smoke.mjs      # یا: npm test
```

تست، کل مسیر را با **jsdom** و **تایمر جعلی** در چند میلی‌ثانیه اجرا می‌کند و یک **AudioContext جعلی سخت‌گیر** دارد که این‌ها را می‌گیرد:

- `NaN` یا `undefined` در هر پارامتر صوتی
- رَمپ نمایی به صفر (خطای رایج Web Audio)
- زمان منفی برای پارامترها
- هر استثنای uncaught / unhandled rejection

خروجی سالم:

```
27/27 تست موفق
🎉 بدون هیچ خطای اجرایی
موتور صدا: gain=135 osc=112 noise=25 filter=73 panner=21 reverb=1
```
